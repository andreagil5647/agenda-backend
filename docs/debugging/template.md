# NNNN. Short description of the symptom

- Date found: YYYY-MM-DD
- Area: e.g. recurrence, auth, tooling
- Fixed in: commit or pull request link

## Symptom

What was observed, with the exact error message or wrong output.

## Reproduction

The smallest steps or input that trigger it.

## Investigation

Hypotheses in the order they were tried, what each check showed, and the tools used
(debugger, logs, `git bisect`, a failing test, …).

## Root cause

Why it happened, in one or two paragraphs.

## Fix

What changed and why that is the right place to fix it.

## Regression guard

The test (with a link) or check that fails if the bug comes back.

## Takeaway

What to do differently next time, if anything.
